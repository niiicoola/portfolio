# Portfolio personale

Portfolio personale realizzato con Docusaurus. La homepage presenta il profilo, i link principali e l'accesso alla documentazione tecnica.

## Sviluppo locale

```bash
npm install
npm start
```

Apri <http://localhost:3000> nel browser.

Per verificare la build di produzione:

```bash
npm run build
npm run serve
```

## Personalizzazione

Aggiorna i placeholder `Nome Cognome`, `tuo-username` e `tua-email@example.com` in:

- `src/pages/index.tsx`
- `docusaurus.config.ts`

La documentazione tecnica vive nella cartella `docs/`.
